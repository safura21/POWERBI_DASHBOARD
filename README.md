# HR Analytics Dashboard

## 📊 Project Overview

This project is an **HR Analytics Dashboard** created using **Microsoft Power BI**.

The dashboard analyzes employee data and provides useful insights about employees, departments, salaries, and workforce performance through interactive visualizations.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* Excel / CSV Dataset
* Data Cleaning & Transformation
* Data Analysis
* Data Visualization

## 📌 Dashboard Features

* Employee count analysis
* Department-wise employee analysis
* Salary analysis
* Employee performance analysis
* Department performance comparison
* Interactive charts and graphs
* Cards and KPIs
* Filters and slicers
* Interactive HR reporting

## 🔄 Project Process

1. Imported the employee dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Prepared the data for analysis.
4. Created KPIs and calculated measures.
5. Created charts, tables, and visualizations.
6. Added filters and slicers for interactive analysis.
7. Designed the final HR Analytics Dashboard.

## 🎯 Objective

The objective of this project is to analyze employee data and convert raw HR data into meaningful visual insights that can help understand workforce trends, salary distribution, department performance, and employee information.
